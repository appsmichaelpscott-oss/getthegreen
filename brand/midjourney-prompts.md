# Get the Green — Logo Direction Prompts (for Midjourney)

Brief: the brand should feel unmistakably cannabis — not shy about it — while
staying modern and premium, not clip-art or cartoonish. Bold, high-contrast,
dark background. Avoid a literal, cartoonish leaf sticker; aim for the leaf
(or another cannabis cue) abstracted into something confident and geometric,
the way Firefox abstracts a fox or Twitter abstracts a bird.

Brand colors already locked in from the site: emerald green `#3EDCA0`,
blue `#5DA9FF`, dark background `#0A0D0C`. Feed these hex codes into
Midjourney directly if you want tighter color matching (Midjourney honors
hex mentions reasonably well, though not perfectly).

Run several, download what you like, send it back — from there it gets
built into real favicon/app-icon sizes and wired into the actual site.

---

## Option 1 — Abstracted cannabis leaf (geometric, not literal)
Leans hardest into "yes, this is a weed site," but keeps it sharp and modern
instead of botanical or sticker-like.

```
Minimalist abstract logo icon, cannabis leaf simplified into
3-4 bold geometric blades, not botanical, not clip art, single
continuous line or solid flat shape, emerald green on near-black
background, modern tech brand aesthetic, sharp angular edges,
flat vector, app icon style, no shading, no realistic texture
--ar 1:1
```

## Option 2 — Bud/nug silhouette as the mark
Softer than a leaf, still unmistakably cannabis, reads well as a small badge.

```
Minimalist logo icon, single cannabis bud silhouette abstracted
into a rounded geometric badge shape, bold flat emerald green,
dark background, modern dispensary branding, clean vector,
confident and simple, not photorealistic, not illustrative,
app icon style --ar 1:1
```

## Option 3 — Trichome/crystal sparkle
A more oblique cannabis reference (the crystal coating on quality flower) —
reads as premium/quality-focused rather than just "leaf = weed."

```
Minimalist logo mark, cannabis trichome crystal abstracted as a
faceted geometric spark or star shape, emerald green with subtle
cyan highlight, dark charcoal background, premium modern cannabis
brand aesthetic, flat vector, sharp faceted edges, no gradient
mesh, no realistic rendering --ar 1:1
```

## Option 4 — Rolling paper / smoke wisp gesture
The most abstract option — evokes cannabis culture/ritual without any plant
imagery at all. Good backup if the leaf options feel too on-the-nose.

```
Abstract minimalist logo, single fluid curved line evoking a
wisp of smoke rising, emerald green gradient to soft white, dark
background, modern cannabis lifestyle brand, elegant and simple,
one continuous stroke, no leaf, no plant, flat vector --ar 1:1
```

## Option 5 — Leaf + "G" monogram fusion ★ (recommended starting point)
Combines the brand initial with an unmistakable cannabis cue in one mark —
probably the strongest single option to start with.

```
Modern logo icon combining a single abstracted cannabis leaf
blade with the letter "G", bold geometric fusion, flat emerald
green, dark background, tech-forward cannabis brand, clean
vector, confident simple shape, app icon style, no clip art,
no realistic botanical detail --ar 1:1
```

---

## Full wordmark option (no icon)
Worth generating alongside the icon options — sometimes the name alone,
in strong custom lettering, is the whole logo (see: Coinbase, Robinhood).

```
Bold modern wordmark logo design, text reading "Get the Green",
custom lettering, rounded geometric sans-serif, weighted heavier
on "Green", dark background, single accent color emerald green
with subtle cyan-blue glow, minimalist, high contrast, tech
startup branding, flat vector, no gradient orb --ar 16:9
```

---

## What to send back
Whatever image(s) you land on — PNG or the raw Midjourney output is fine.
From there: extraction into a transparent-background icon, proper favicon
sizes (16/32/180/512px), and wiring into the actual site file (header pill,
browser tab title, footer) all happens on this end.
